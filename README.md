# ailonn

Information first. Software that does one thing well.

## Values (pinned since 2018, still true)

- **Crocker's Rules** — [gist](https://gist.github.com/ailonn/5c2eef4b4aa30ec94fdfdab4f9914e38): people may optimize their messages for information, not for being nice to me. A discipline I run for myself.
- **Bitreich Manifesto** — [gist](https://gist.github.com/ailonn/b81cf5eb3d84418b233c3497dde5809d): small, understandable, CLI-first software; bug reports should be patches.
- **Ethical Design** — [gist](https://gist.github.com/ailonn/ed539f08a01a2ab14a2c54db6a42ad84): technology that respects human rights, human effort and human experience.

## 2018 → 2026: the direction held, the edges bent

The manifesto sets the direction; daily use corrects it. Two documented cases:

- **The license** — "enforce GPLv3" (2018) became **MIT by default, copyleft only when justified** (2026 — annotated on the manifesto itself).
- **The three 2018 gists are about the individual; the work happens in a team** — 2026 adds the missing dimension: the Agile principles I actually live, a curated selection of the twelve ([the 12 principles, the ones I live](https://gist.github.com/ailonn/97255b16ae2a6a22d3cb46e84969ad06)).

## Practice, not just principles

- **AI-assisted workflow, versioned like code** — my OpenCode environment ships with custom skills, agents and MCP servers; the tooling is spec'd, TDD'd and reviewed like application code. (Public `opencode-*` repos to follow.)
- **Craftsmanship** — "we are not just building software, we are crafting it" ([2009](https://craftsmanship.software/), still true): spec first, tests first, one thing done well per commit.
- **Rust, learned in public** — [aoc2025](https://github.com/ailonn/aoc2025) (Advent of Code in Rust) · [rust-guessing-game](https://github.com/ailonn/rust-guessing-game) (first steps + unit tests) · [jeu_de_la_vie](https://github.com/ailonn/jeu_de_la_vie) (Game of Life as a discovery vehicle).
- **Knowledge in plain markdown** (Foam, Zettelkasten) — notes should be as recompileable as source.

**Honest line:** the manifesto is the ideal, the reality is a working engineer in the energy-tech industry. The work happens in the gap between the two.
